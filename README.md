## 🚀 Getting Started

### Prerequisites

- Node.js 18+ or 20+
- npm or pnpm or yarn

### Installation

```bash
# Clone the repository
git clone https://github.com/Vishwakarmasuraj333/suraj-portfolio3.git

# Enter project directory
cd suraj-portfolio3

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit [http://localhost:3000](http://localhost:3000) to view the application.
